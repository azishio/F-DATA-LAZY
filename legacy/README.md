# Legacy scripts

The original pandas-based scripts that produced the published F-DATA release
(https://doi.org/10.5281/zenodo.11467483), kept unchanged as the reference
implementation for parity checks. They assume the authors' directory layout
(monthly `or_data_splits/` CSVs, `anon_data_splits/`, `F-DATA/`) and are not
runnable as-is; use the `fdata` CLI at the repository root instead.
